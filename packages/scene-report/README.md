# Scene Report

A small, complete Floptle package: one panel, one menu item, one shortcut, one
Scene-view overlay, and world-space handles.

Install it with **Window ⏵ 📦 Packages ⏵ ✚ Add ⏵ Choose folder…** and pick this
folder. Then **Scene Report ⏵ Report…**, or press `Ctrl+R`.

`editor/main.lua` is the whole thing, and it is meant to be read: every part of
the editor API a package is likely to reach for appears in it once. See
[editor-scripting.md](https://github.com/Fopull-LLC/Floptle/blob/main/docs/editor-scripting.md).
