# Floptle v0.111.2 — "Sharp Mark"

A Hub release. The Floptle mark at the top of the Hub is clean again.

## The logo reads as a drawing

The mark beside the Hub's name was drawn too small for its fine lines, and
shrinking it made them break up into a scatter of dots. The header is a
little taller now and the mark is larger, with the Hub's version tucked
under its name. The mark is also shrunk smoothly to the exact size it is
shown at, so it stays crisp at any display scaling. The logo on the About
page gets the same treatment.

## Upgrading

Open the Hub and press **Update and restart**. The engine is unchanged in
this release, so your projects don't need to move.
