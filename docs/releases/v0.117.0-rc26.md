# Floptle v0.117.0-rc26 — "Whole Worlds" (beta)

Everything in rc25, plus beta updates as one switch in the Hub, and versions
listed in the right order.

## Beta updates, one switch

The Hub's update channel is now a single setting: **Settings → Beta updates
→ Enable beta updates**.

- Off (the default), the Hub lists and offers stable releases only.
- On, beta releases appear beside the stable ones, marked **beta**, and a
  newer beta is offered as an update. The Hub's own updates follow the same
  switch.
- If you had chosen the beta channel before, the switch starts on.

## Versions in order

The Hub listed versions as text, so 0.117.0-rc22 sat below 0.117.0-rc3. It
now orders them by version, newest first, wherever it lists, picks a default
or offers an update. The same fix corrects how a project's upgrade compares
pre-release versions.

## Also

`floptle exec`'s `json.encode` writes a number in a table that lies beside 0
or 1, such as `1e-20`, as itself, as the game's `json.encode` already does.
