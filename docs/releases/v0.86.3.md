# Floptle v0.86.3

One fix, finishing the one before it.

## Your server's address comes from your server

The last release taught a dedicated server to report where it can actually be
reached — the port it is listening on, or the relay it went out through — because
a server hosted through a relay listens on no port at all, while the address
being published for it said otherwise.

The agent that runs your server on a Floptle Cloud region read that and then
threw it away, so the correction reached somebody standing at the machine and
never reached your game's page. It carries it now.

Nothing about this is visible in the editor. If you host on Floptle Cloud, it is
the difference between a published address that means something and one that was
guessed.

## Upgrading

Nothing to do. If you run a region box, take the new fleet agent.
