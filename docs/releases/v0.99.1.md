# Floptle v0.99.1 — "Keeps Serving"

A patch for dedicated servers on Floptle Cloud. Nothing in the editor, the Hub
or your game changes; the fix is in the agent that runs servers on Floptle
Cloud's machines, which Floptle Cloud updates.

## Big server builds deploy

A server build is downloaded onto the machine that runs it, and that download
was given 30 seconds in total. A build of more than about 140 MB could not
arrive in time, so it never deployed, and one near 100 MB was a coin toss.

The download now gives up only when nothing has arrived for a minute, however
long the whole build takes. A download that is cut off keeps what it already
has, and the next attempt carries on from there instead of starting over.
Every build is still checked against the fingerprint you uploaded before it
runs.

## A failed update never takes a running server down

When a new build could not be downloaded, the server was marked failed, and
the server already running your game, with its players, was stopped. Now the
running server keeps running until the new build has arrived and been checked.
Your game's page shows why the update is waiting, and it is tried again every
few seconds.

## Upgrading

Nothing to do. If a server build failed to deploy on 0.99.0 because of its
size, deploy it again once Floptle Cloud is on 0.99.1.
