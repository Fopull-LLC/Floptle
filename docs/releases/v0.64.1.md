# Floptle v0.64.1

Everything in [v0.64.0](v0.64.0.md) — spot lights, the `F`-key fix for nodes
inside other nodes, and five new capabilities for editor packages. **v0.64.0
itself never shipped**: a check in our own build caught a fault in one of the
release tests and stopped it before anything was published, so this is the first
build of it you can install.

Nothing in the engine changed between the two. If you are coming from 0.63.0,
[the 0.64.0 notes](v0.64.0.md) are the ones to read.
