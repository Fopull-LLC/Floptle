# Floptle v0.111.3 — "Asks First"

A web game no longer stops on an iPhone when it takes the mouse or goes
fullscreen.

## A web game plays on an iPhone

- **Mouse look.** A game that locks the mouse for a free-look camera
  stopped on an iPhone the moment it asked, with "requestPointerLock is
  not a function". Safari on an iPhone has no pointer lock. The game now
  checks whether the browser has it before asking, and carries on without
  it where it is missing. An iPad, and every desktop browser, still lock
  the mouse as before.
- **Fullscreen.** `app.setFullscreen` and the F11 and Alt+Enter keys
  stopped the game the same way on an iPhone, which has no fullscreen for
  a game's page. They now do nothing there, and fill the screen everywhere
  that can.

## Upgrading

Export your web build again and upload it. Nothing in your project changes.
