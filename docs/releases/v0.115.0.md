# Floptle v0.115.0 — "Paints True"

Getting a 2D game started is quicker. A spritesheet goes straight onto a tile
layer, the pixel pencil paints the pixel under the pointer, and Ctrl+S saves
from any tab.

## Your spritesheet goes straight onto the layer

A new tile layer's **◫ Tiles ▸ TILESET** section now asks for your
spritesheet. Drag a PNG onto it from Assets, or pick one from the
**choose an image…** list there. The layer gets a tileset cut from that image,
and its tiles show up in **PALETTE**, ready to paint.

- **The cut comes from your art.** An image drawn in the 🖼 Image tab with
  **This image is a sheet** ticked is cut on the grid you drew it against.
  Otherwise a cell size in the file name (`tiles_16x16.png`) is used, and
  failing that the image's size. Check it on the **SHEETS** row and change
  cols / rows if it is wrong.
- **You can drop the drawing itself.** A `.flimg` from the Image tab works as
  well as the PNG saved beside it.
- **One tileset per spritesheet.** Dropping an image that already has a
  tileset gives the layer that tileset, with its collision and autotiling,
  instead of a second copy.
- **Nothing to set on the material.** The layer draws the tileset's image
  directly.
- **+ Empty tileset** makes a tileset with no image yet, and its **SHEETS**
  row is where the image goes.

This used to be a dead end. The only button wanted the layer's material to
have a spritesheet already, and the palette sent you to a **SHEETS** section
that did not exist yet.

## The pencil paints where you point

In the 🖼 Image tab:

- **A click paints a pixel.** A press that did not move used to paint
  nothing.
- **Both ends of a line land.** A stroke now starts on the pixel you pressed
  and ends on the pixel you let go over. It used to start a few pixels along
  and stop short.
- **The pixel under the pointer is the pixel that paints**, wherever in it
  the pointer is. The pixel pencil used to miss a pixel when the pointer was
  near its corner, which made the brush feel a step behind.
- **Fast strokes keep their shape**, even at a low frame rate. Every position
  the mouse reported is painted, not only the last one in each frame.
- **A stroke can run off the edge of the canvas** and still reach the edge
  pixels.

## Ctrl+S saves from anywhere

Ctrl+S saves the scene, project, tilesets, open image and scripts from any
tab. It used to do nothing while the Game tab was in front or a text field
had focus, including the script editor, a search box or a number you had just
typed. That was why saving seemed to work only in the Scene view. In the
script editor it still saves the open script too, formatted if you have
format-on-save on.

## Also fixed

- The ◫ Tiles brush preview shows tiles from a tileset's own image. It used
  to stay blank unless the layer's material had the same image.

## Upgrading

Nothing to do. Existing tilesets, layers and images are unchanged.
