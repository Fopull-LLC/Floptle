# Floptle v0.111.0 — "Make It Yours"

The editor and the Hub now look like Floptle, and how they look is yours to
change. The default theme is the brand you know from fopull.com, twelve
themes come built in, and a theme is a file you can edit, swap and share:
colours, type, corners, and pictures or moving backgrounds behind any panel.

## The Floptle look, by default

- **Floptle Dark** is the new default: near-black panels, fine hairlines in
  place of shadows, and one teal accent for the action that matters.
- **New type**: IBM Plex Sans for everything you read, IBM Plex Mono for
  code, ids, versions and paths, and Bricolage Grotesque for titles. Every
  icon in the editor still draws.
- **The Hub matches the website**: the Floptle mark on its soft glow, tabs
  like the site's, one filled button for the main action in each view, and
  the same green, amber and red for good, warn and bad.

If you chose a theme before, you keep it.

## Twelve themes to start from

Pick one in **Edit ▸ Preferences…** in the editor, or in **Settings** in the
Hub. Choosing in either changes the other within a second.

- **Floptle Dark** and **Floptle Light**
- **Midnight**, **Slate** and **Carbon (OLED)**
- **High Contrast** and **High Contrast Light**: bold edges, larger text,
  Atkinson Hyperlegible, and no animation
- **Galaxy**, **Aurora**, **Retrowave** and **Terminal**: panels over a
  moving backdrop
- **Paper**: warm cream and ink, a light theme with less glare

## Make your own

Choose a theme and press **Customize…**. The theme editor changes the window
as you go: every colour, the typefaces and text size, corner radius, line
width and spacing, and a backdrop and picture for each region. Save it and
it is yours.

A theme can give each part of the window its own look: one picture behind
the Inspector, another behind the Hierarchy, a moving shader behind
everything else. It can bring its own fonts, pictures and shaders written in
WGSL. Save a theme's file in a text editor and the window redraws in it.

## Share a theme

**Export…** saves a theme with everything it uses as one `.floptletheme`
file. Drop that file on the editor or the Hub to add it. Packages can carry
themes too, and choosing one from a package keeps it for every project.
`docs/themes.md` covers the format.

## Fast on purpose

A moving backdrop is drawn at half resolution, at most 30 times a second,
and only where a panel shows it: a fifth of a millisecond or less each time on
a desktop graphics card. **Effects** in the theme settings switches to
**Still** (drawn once and held) or **Off** (colours only), and backdrops hold
still while your game plays.

## Upgrading

Nothing in your projects changes. If you never chose an editor theme, you
get Floptle Dark.
