# Floptle v0.42.0 — "Off Means Off"

A release about the engine getting out of your way. Shortcuts that stopped
working now keep working, a tile floor you painted solid stays solid after you
close the project, switching a node off actually switches it off — and there is
a full colour-grading and lens chain on the post-processing node.

---

## Ctrl+C stops dying halfway through a session

Copying nodes between scenes, and copying keyframes in the Animating tab, could
quietly stop working — and stay stopped until you clicked in the right place by
accident. So could Delete, Ctrl+V, Ctrl+D, F to frame the selection, and the
animator's Space, arrows and Ctrl+Z.

The editor was treating **any clicked widget** as "the user is typing", so
everything that yields to a text field yielded to a button, a checkbox, a slider
or a dropdown as well. One click on a toolbar and the shortcuts were gone.

Only a real text field takes the keyboard now. Nothing to do on upgrade — the
keys you already know just keep answering.

## Tile collision survives closing the project

Collision shapes, solid flags, autotile groups and tags live in your tileset
file — and **Ctrl+S was not writing it**. The only thing that ever saved a
tileset was a small `Save` button inside the ◫ Tiles tab, so a level came back
looking exactly right and colliding with nothing.

Save-everything now means everything, and closing with unsaved tileset work asks
first, the same as an unsaved scene.

**Check your tilesets after upgrading.** If you drew collision and never pressed
that button, it was never written; you will need to draw it once more, and this
time it stays.

## Falling through a floor you painted solid

A tilemap needs a collider before anything can stand on it, and that is still
not automatic — most projects paint background layers from the same sheet, and
turning collision on for those would be worse. But the Inspector now says so, on
the layer, with the fix on a button:

> ⚠ 34 solid squares, but nothing collides with this layer
> `▦ Make this layer solid`

## Scenes that refused to open

Double-clicking some scenes did nothing at all. They were failing to parse — one
missing line in the file — and the only report went to a terminal that usually
isn't there.

Two changes: every field in a scene, project and material file now has a
sensible default, so a missing line costs that line and not the whole level; and
when a file genuinely can't be read, the Console says which file and what is
wrong with it.

## Switching a node off now means something everywhere

A disabled node doesn't draw, doesn't collide and its scripts don't run. It was
still being picked up as **the active camera**, and still being handed back by
`find()` — so a retired camera kept rendering the game and a retired player kept
being adopted by scripts that had no way to know.

- **A switch on the Inspector's name row.** One click, always visible, works on
  the whole selection at once. If a parent is what switched a node off, the line
  underneath says so.
- **`find()`, `findAll()`, `findScript()`, `findScripts()`, `findTagged()` and
  `node:find()` skip switched-off nodes.** Every one takes an options table if
  you want the old behaviour:

```lua
find("Player")                          -- enabled only (the default)
find("Player", { scope = "all" })       -- switched-off ones too
find("Spawner", { scope = "disabled" }) -- only the switched-off ones
findAll("Enemy", { includeDisabled = true })
```

  If a lookup comes back empty while a switched-off node of that name is sitting
  in the scene, the Console says so once, and names the option that reaches it.

- **The Hierarchy has a search box**, with the same three scopes. It defaults to
  enabled-only. Switched-off nodes are never hidden from the tree itself — that
  is where you turn them back on.

**Worth knowing on upgrade:** if a script relies on finding a node you keep
parked and switched off, add `{ scope = "all" }` to that call.

## A colour grade, a lens, and a real depth of field

The Post Processing node grew a full look chain. Everything below is off at its
default, costs nothing while it is off, and none of it changes an existing
scene.

**Colour grade** — exposure in stops, contrast, saturation, temperature and tint
(the green–magenta axis a single temperature slider can never reach), and
lift / gamma / gain for shadows, midtones and highlights. Exposure is a real
stop, contrast pivots on mid grey rather than darkening everything as you add
it, and desaturating leaves brightness where it was.

**Lens** — chromatic aberration and barrel / pincushion distortion, together,
because they are the same lens. A bent frame's corners go black rather than
smearing the edge pixel outward.

**Depth of field** — a focus distance, a range that stays sharp, and how wide
the blur gets. Round bokeh, and a sharp foreground does not bleed onto a
defocused background.

**Sharpen** — clamped so edges get crisper without growing a bright halo.

**Denoise** — averages inside flat areas and refuses to average across an edge.

**Film grain** — multiplicative and strongest in the midtones, the way film
actually responds, with a grain size so it stays visible under a retro upscale.
Added grain lifts every shadow into grey mud; this doesn't.

Not in this one: **motion blur**. It needs the renderer to remember where things
were last frame, which is its own piece of work, and a slider that did nothing
would be worse than not having one yet.

## The image editor holds more than one image

Opening a second image used to evict the first, and closing an image you had
never named was impossible — it asked you to save first, and there was nothing
to save it as. The 🖼 tab was a room you could get stuck in.

- **A tab strip.** Several images open at once; switching keeps each one's zoom,
  selection and undo history. Double-clicking an image that is already open
  switches to it instead of reloading over your unsaved work.
- **Closing asks properly** — Save & close, Discard, or Cancel.
- **Paste an image from anywhere.** Copy a reference in a browser or take a
  screenshot, then Ctrl+V in the 🖼 tab. **File ⏵ New from clipboard** makes a
  document at the image's own size. Ctrl+C sends your selection back out to the
  system clipboard, so it pastes into other programs too.

## Feed a texture into a shader from a script

A `.flsl` shader could always declare up to eight texture slots — but they were
fixed at whatever the Inspector was set to when the scene was saved.

```lua
node:setShaderTexture("decal", damaged and "textures/scorch.png" or "")
node:setShaderTexture("screen", "rt:securityCam")   -- another camera, live
```

Slots are named the way the shader names them. `""` clears one.

## Name your assets when you make them

✚ Effect asked for nothing and made `NewEffect`, then `NewEffect1`. It asks for
a name first now, and the file is born with it — so nothing is ever pointing at
a placeholder you meant to rename.

## The Map tool is the Model tool

It builds far more than maps, so it is called what it is: the **▦ Model** tab,
Model shapes, a Model Mesh. Only the words changed — your scenes, files and
keybinds are untouched.

## Zero light intensity, and a scene you can still see

Intensity is the brightness of the *key* light, not a master dimmer — ambient,
the 2D base light, point lights, emissive and unlit materials are all separate,
and none of that was discoverable from the panel.

Turn the key light to 0 now and the Lighting node lists what is still lighting
the scene, with a **🌑 Black it out** button for the two fills it owns.
